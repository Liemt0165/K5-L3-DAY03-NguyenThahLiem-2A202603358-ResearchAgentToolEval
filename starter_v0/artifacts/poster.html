🎯 A1. Agent Này Làm Được Gì?

🧪 A3. Câu Hỏi Mẫu Để Thử Trực Tiếp

  • 1. Tin tức Web:
    "Tìm tin tức AI hôm nay có gì nổi bật trên web?"
    👉 Agent gọi lookup(query='AI', topic='news', timeframe='day')
  • 2. Đọc & Tóm tắt Link:
    "Tóm tắt bài viết này giúp mình: https://openai.com/blog/gpt-5"
    👉 Agent gọi fetch đọc URL và tóm tắt
  • 3. An Toàn Trước Khi Gửi:
    "Đăng bản tin tóm tắt này lên Telegram giúp mình"
    👉 Agent KHÔNG tự gửi, hỏi lại xác nhận clarify(yes_no)
  • 4. Tìm Kho Mã Nguồn:
    "Tìm 5 repository GitHub phổ biến nhất về topic AI agent evaluation"
    👉 Agent gọi tool mới github_search
  • 5. Xử Lý Khi Thiếu Link:
    "Tóm tắt bài viết này cho mình nhé" (chưa có link)
    👉 Agent lịch sự hỏi link URL, cấm tự bịa đặt
